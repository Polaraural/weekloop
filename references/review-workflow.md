# 对话式复盘：流程与提问脚本

这个文件规定「用户想复盘」时，助手应该怎么问、怎么记、怎么收尾。

## 核心原则

1. **一次一条**。不要一口气抛出 20 个问题。用户是在回忆和反思，不是填问卷。
2. **原话优先**。用户说"刷手机到 1 点"，就记"刷手机到 1 点"。不要改写成"因娱乐耽误休息"这种你的总结。
3. **不替用户判定**。含糊的回答追问一句，落到 `完成` / `部分` / `未完成`，别自己猜。
4. **随手落盘**。确认一条就写一条，不要攒到最后一起写——中途中断也不会丢。
5. **不追问没提的条目**。用户想聊哪几条就聊哪几条。

## 第一步：读取现状

```bash
python3 scripts/obsidian_plan.py show-week --vault "/path/to/Vault" --week 1
```

拿到这一周每天的安排，以及已经有的复盘批注。

## 第二步：抛"待复盘清单"

筛出「已经过去 + 有内容 + 还没有复盘标记」的条目，按天分组，**一次不超过 6–8 条**。

推荐说法：

> 第 1 周里这几项还没有结论：
>
> **周一** · 5:00–5:30 起床 + 洗漱 / 6:10–7:10 收集灵感
> **周二** · 第一节课 写视频稿 / 19:00–20:00 剪视频
> **周三** · 第三节课 工作三
>
> 你想从哪几个开始聊？也可以说"就聊周一"。

要点：

- 给**分组**和**数量**，让用户能挑，而不是被迫全过。
- 明确允许跳过。

## 第三步：逐条提问

### 通用问法

- "周三 19:00 那段写的是剪视频，实际做了吗？"
- "5 点起床这条没打勾，是没起还是起了但没记？"
- "完成度大概什么样？做完了、做了一半，还是基本没动？"

### 追问（用户回答含糊时）

- 用户："算做了吧"
  → "那我记成**完成**；如果只是做了一部分，我就记**部分**——哪种更准？"
- 用户："差不多吧"
  → "差不多是指做了一半左右吗？"
- 用户："没做"
  → "行，记**未完成**。当时是什么情况？不想说也可以，只记状态。"

### 记录原因（用户愿意说时）

可以直接问，但**不要逼问**：

- "没做到的话，当时在忙什么？"
- "下次想怎么调整？"（可选，用户不说就不写）

### 边界

| 情况 | 处理 |
| --- | --- |
| 用户说"跳过"/"不想聊" | 跳过，继续下一条，不追问理由 |
| 用户明显在自责 | 不评判、不安慰式说教，只把事实记下来，然后推进到下一条 |
| 用户想改计划内容本身 | 走 `set-cell` 改内容，不是复盘 |
| 用户描述与笔记内容不符 | 先确认："笔记里写的是剪视频，你说那天在拍视频——要我改掉笔记里的内容吗？" |
| 涉及健康、隐私等敏感原因 | 可以只记状态、不记原因 |

## 第四步：随手写回

```bash
python3 scripts/obsidian_plan.py set-review --vault "/path/to/Vault" \
  --week 1 --row "19:00 - 20:00" --day 周三 \
  --status 未完成 --note "本来说剪视频，结果刷了 1 小时短视频"
```

- `--status`：`完成` / `部分` / `未完成`
- 只补批注、不动状态：**省略 `--status`**
- 清除：`--status 清除 --note ""`

写完后可以顺口回报一句"记下了：周三 19:00 未完成"。不用每次都长篇确认。

## 第五步：收尾统计

聊完给出这周的整体情况：

```
第 1 周复盘
  完成   3 项  ✓
  部分   2 项  ~
  未完成 2 项  ✕
```

统计方式：

```bash
python3 scripts/obsidian_plan.py list-reviews --vault "/path/to/Vault" --week 1 --json
```

然后可以问：

> 要不要顺手把下周的预排也写进去？（或者：要不要我把这些零散批注整理成一段周复盘？）

## 第六步（可选）：提炼周复盘

如果用户要一段成文的复盘，把零散批注归纳成几段，追加到该周笔记正文末尾、**批注区块之前**。

硬性要求：

- **只做归类，不新增事实**。不要脑补"这说明你的自控力需要提升"这类判断。
- 保留用户原话中的关键措辞。
- 明确区分事实与用户的自我评价。
- 写之前先把草稿给用户看一眼，确认后再落盘。

示例：

```markdown
## 本周复盘

**做到的**
- 周二、周三的写稿都推进了，周三效率最高。

**没做到的**
- 周一 5 点没起来（原话："刷手机到 1 点，赖床到 5:40"）。
- 周二晚上计划剪视频，实际刷了 1 小时短视频。

**下周调整**
- 23:30 前放下手机。
```

## 完整对话示例

> **用户**：帮我把这周复盘一下。
>
> **助手**：好，我先看了第 1 周。这 6 项还没有结论——
> 周一 5:00 起床 / 周一 6:10 收集灵感 / 周二 第一节课 / 周二 19:00 剪视频 / 周三 第三节课 / 周三 20:40 放松。
> 想从哪几个开始？
>
> **用户**：周一吧，早上那个没起来。
>
> **助手**：记**未完成**。当时是什么情况？
>
> **用户**：前一天刷手机刷到一点多。
>
> **助手**：记下了——周一 5:00 未完成，批注"前一天刷手机到 1 点多"。
> 那周一 6:10 那段的"收集灵感、搭稿子框架"呢？做了吗？
>
> **用户**：那个做了，框架搭出来了。
>
> **助手**：记**完成**。还继续往下聊吗，还是先到这儿？
